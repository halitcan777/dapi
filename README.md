# DAPI

Сайт команды DAPI. Делаем сайты; рядом — автоматизации, ИИ, исследования, ВПН.

Интерфейс построен по мотивам рабочей среды разработчика: слева дерево
разделов, в центре — единственная скроллящаяся зона, справа — лента работ.

## Как устроено

- `index.html` — весь макет и логика навигации
- `сетка.css` — система: модуль 35px, 42 колонки на 1470, стыковка линией 1px
- `фото/` — портреты команды

Девять разделов идут одним общим потоком (о нас, команда, сайты — там же
плиткой кейсы, автоматизации, контакты, ии и llm, исследования, впн,
процесс). В ряду вкладок продублированы только первые четыре (о нас,
команда, сайты, автоматизации) — вкладки продают сайты, остальное
доступно скроллом или деревом слева, без отдельной вкладки.

«Мероприятия» — единственный раздел-окно: открывается только из дерева
слева, поверх основного потока.

Клавиша **G** показывает направляющие сетки.
